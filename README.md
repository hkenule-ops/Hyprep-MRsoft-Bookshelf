# HYPREP Training Portal

Digital training materials platform for the **Hydrocarbon Pollution Remediation Project (HYPREP)**.

Built and handled by **MRSoft**.

## Branding

- **App name:** HYPREP Training Portal
- **Colours:** Nigerian flag green (`#008751`) + white (HYPREP / national palette)
- **Logos:** Dual — HYPREP + MRSoft
- **Users:** Admins and Trainees (not "students")

## Overview

Admins manage courses, trainees, and training materials.  
Trainees access only the courses assigned to them.

React + Vite + Tailwind + shadcn/ui frontend with Google Apps Script / Sheets backend.
